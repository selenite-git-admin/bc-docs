# Platform DB machinery home: dedicated repository bc-db (DB as a product)

## Context

Operator decision 2026-09-09 (Platform DB Foundation Program, TSK-cc348a, decision D3 of docs/design/platform-db-foundation-requirements.md, bc-core PR #748). The database is a shared multi-process, multi-database asset (served API, owner-plane worker, seed/maintenance identity, operator runbooks, CI harness, audit and scratch databases on one cluster); the API server is its primary client, not its owner. A dedicated home gives the spine and machinery an independent version and release unit consumed by bc-core, bc-infra and tooling, and keeps owner credentials and cloud-administration clients out of the served API's import graph. The cross-repository coordination cost is accepted deliberately; the independent auditor's acceptance of the in-repo default as sufficient (RESPONSE-Codex-d597-20) is noted and superseded by this operator choice.

## Decision

The platform database's schema spine (canonical baseline, forward-only migrations, roles/grants, engine/tool version contract, tenant static baseline and upgrades), deterministic master-data seeds, curated-content exports, the DB-management machinery (runner, baseline capture-mapping and equivalence, content promotion, fleet upgrade, backup/restore rehearsal, evidence/custody tooling, drift observation) and immutable release manifests are owned by a dedicated repository, selenite-git-admin/bc-db, released on its own cadence. bc-core remains the database's primary client and consumes the machinery package with a declared compatibility range (expand/contract rollout, never exact-version-at-boot). bc-infra remains the instance-provisioning layer. Repository location never decides SQL privilege or deployment unit. The repository was created 2026-09-09 as a scaffold (initial commit 4359985cfb15ba0289d9db189501afdbd47e1ecb; CI quality gate; bc-core-parity branch protection; DevHub project bc-db); content lands only through reviewed Platform DB Foundation Program units under the Database Change Protocol. Supersedes the program's earlier proposed default of a governed package inside bc-core.
