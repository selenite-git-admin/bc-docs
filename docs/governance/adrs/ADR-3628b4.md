# Retire the TSK-3f52d7 schema-acquisition launcher (F7) and its acquisition execution package; close bc-core PR #746; quarantine the schema comparator core for W1.2 (D7)

## Context

Ratified by the operator on 2026-09-09 ("ratify D7; Codex may review and merge the retirement PR", with the instruction to trace and gracefully retire all work traces via a grounded survey). The operator selected path B for baseline capture (D12, DEC-c99f72): a reviewed read-only script under a written per-run authorization, now built and fixture-tested (bc-db PR #5). The launcher's signing ceremony, process guards and Linux target were built for the de-drift flow that the program mandate (DEC-75fc71) superseded; the survey on bc-core main found no importer of scripts/comparator outside the package itself, so the retirement removes unreviewed, unused surface. The comparator core is kept because W1.2 may reuse a schema canonicalization/comparison primitive; that reuse is a reviewed decision, not an assumption.

## Decision

The schema-acquisition launcher package built under TSK-3f52d7 — bc-core scripts/comparator/f7/** (launcher, operator-approval seal and loader, child, closure, evidence, docker binder, Linux run harness, native prctl binding, retained-gates note) and the acquisition execution package in scripts/comparator/ that exists only to serve it (acquire-schema, acquisition-runner, -supervisor, -attest, -record, -success-receipt, -authorization grammar and specs, durable-write, evidence-assembler, execution-manifest, fixtures.json, role-map.local-dev.json) — is retired without ever having run a live acquisition, by one bc-core pull request that removes those files and nothing else, reviewed and merged by the independent auditor at an exact head with green CI. bc-core PR #746 (a fix to the launcher) is closed unmerged. The schema comparator core (scripts/comparator/schema-canon.mjs, schema-compare.mjs, scoped-projection.mjs and their tests) is retained but quarantined from use pending the W1.2 equivalence-gate design brief's adopt-or-replace decision. Uncommitted drafts from the arc (the local PR #746 edit, the monolith generator draft scripts/redesign/generate-02-monolith.mjs, the gate-1 authorization package and sealed approval artifacts on the builder's machine) are discarded; the arc's git branches are deleted after the retirement merges. DevHub TSK-3f52d7 is closed; its only surviving scope, the modular-to-monolith assembly rule (DEC-591eb7), is delivered in W5 within bc-db. The auditor's acceptance records for the launcher (d597 exchange, responses 04-13) remain as immutable history.
