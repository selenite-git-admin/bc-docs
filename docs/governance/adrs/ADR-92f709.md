# The certification regime is deterministic-gate-primary: the machine-checkable truth is the deterministic gate; the panel judges only residual true-meaning

## Context

No rationale recorded.

## Decision

The certification regime in force is DETERMINISTIC-GATE-PRIMARY. A governed MCV is CERTIFIED (eligible for the C8 approved→active door) iff, recorded on the certification record (recomputable, Invariant VI): (1) the DETERMINISTIC GATE is green — every machine-checkable class with a live deterministic check PASSES (0036/PE-MC checks + mcv_chain_status: binding resolution, grain agreement, temporal boundary, closure, misbound input, currency policy, vocabulary conformance); a red class is a hard refuse and no panel verdict overrules it; (2) the certification PANEL returns PANEL_VERIFIED on its RESIDUAL scope only (definition↔formula fidelity, ambiguity, filter semantics), under a panel declared FIT per DEC-b5978c D1 on the reduced residual corpus with the D2 moderator-overrule rule enforced; (3) a machine-checkable class whose deterministic check is not yet live is transitionally panel-judged until its check lands, in the DEC-b5978c D5 order (wrong grain → temporal boundary → closure omission → misbound input) — deterministic-primary with a named shrinking frontier. Cert-unpause: new certifications unpause when BOTH the deterministic gate for the machine-checkable classes is built+live AND the panel is declared fit per DEC-b5978c D1 on its reduced residual corpus with D2 enforced. Whether the panel CAN be fit on the reduced corpus remains an open empirical question (G2), not settled here. Re-scopes DEC-b5978c (its D1/D2/D3/D4/D6 govern the panel's residual fitness; D5 is the migration this declares complete-in-direction); does NOT supersede it. Realizes DEC-c48b0f §4 (anything machine-checkable belongs to deterministic surfaces, never a panel).</decision_text>

So deterministic-gate-primary is the written completion of the existing direction, not a reversal. Operator co-signed the wording as written 2026-10-06, explicitly accepting the G2 caveat.
