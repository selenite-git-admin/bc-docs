# The certification regime is deterministic-gate-primary

**Status:** decided. Authority: operator co-sign of this wording (2026-10-06), recorded as the byte-bound bc-exchange desk decision-grant cited at close. Author: Architect SES-b9b0ef. G1 of the metric#1 (DSO) critical line (TSK-9061e5). Grounded at bc-docs origin/main (metric-lifecycle companion; DEC-c48b0f; DEC-b5978c) via the metric-lifecycle authority ladder (DEC-5a9dee). Re-scopes DEC-b5978c; does not supersede it.

## Context

The definition of "certified" moved three times — panel prove-one → the N=5 panel-fitness standard (DEC-b5978c, 2026-10-03) → an unwritten 2026-10-05 pivot to deterministic-gate-primary — and only the first two were recorded, so every downstream certification gate has been provisional and kept shifting. The pivot is not a new direction: DEC-b5978c D5 ("rules before judgement") already moves each machine-checkable defect class out of the panel to a deterministic PE-MC check, and DEC-c48b0f §4 is explicit — "anything machine-checkable (binding resolution, grain agreement, currency policy, vocabulary conformance) belongs to deterministic surfaces (PE-MC checks, `mcv_chain_status`), never to a panel; a rule discovered by a panel is a missing rule, and the remedy is the rule, not another panel run." The 2026-10-03 calibration (DEC-b5978c F1–F10) also showed the panel is not fit as a primary gate even on clean data — a v10 run verified three planted defects. This ADR writes the regime down and pins the predicate.

## Decision

**(a) Regime in force: DETERMINISTIC-GATE-PRIMARY.** Certification's authority on everything machine-checkable is the deterministic surface (the 0036/PE-MC member-evaluation checks + `mcv_chain_status`), not the panel. The certification panel (panel 2, assessor/adversary/moderator — DEC-c48b0f) is confined to the residual true-meaning that no deterministic rule can decide. This realizes DEC-b5978c D5 + DEC-c48b0f §4; DEC-b5978c D1–D6 are retained, re-scoped to the panel's residual role (below).

**(b) The exact "certified" predicate.** A governed MCV is CERTIFIED — eligible for the C8 `approved → active` door — iff ALL hold and are recorded on the certification record (recomputable, Invariant VI):
1. **Deterministic gate — primary, hard.** Every machine-checkable class that has a live deterministic check PASSES: the 0036/PE-MC checks are green and `mcv_chain_status` is green (binding resolution, grain agreement, temporal boundary, closure, misbound input, currency policy, vocabulary conformance — the DEC-b5978c D5 / DEC-c48b0f §4 classes, as built and live). A red deterministic class is a hard refuse; no panel verdict overrules it.
2. **Panel residual — secondary.** The certification panel returns PANEL_VERIFIED on its residual scope only (see (c)), under a panel declared FIT per DEC-b5978c D1 on the reduced residual corpus, with the D2 moderator-overrule structural rule enforced. The panel never certifies past a red gate and never re-decides a mechanized class.
3. **Transitional frontier.** A class that is machine-checkable but whose deterministic check is not yet live is, transitionally, judged by the panel until its check lands, in the DEC-b5978c D5 migration order (wrong grain → temporal boundary [TSK-e4a016 part 2] → closure omission → misbound input). Each class leaves the panel the moment its deterministic check is live. The regime is deterministic-primary with this named, shrinking frontier — not an assertion that every mechanical class is already deterministic.

**(c) What the gate judges vs what the panel judges.**
- **Deterministic gate** (0036/PE-MC + `mcv_chain_status`): all machine-checkable classes — binding resolution, grain agreement, temporal boundary, closure, misbound input, currency policy, vocabulary conformance. D082-provable; authoritative; no override.
- **Panel** (residual, irreducibly judgment): definition↔formula fidelity, ambiguity, and filter semantics — exactly the classes DEC-b5978c D5 says "the panel keeps". Nothing machine-checkable is a panel question (DEC-c48b0f §4); a machine-checkable property a panel finds is a missing deterministic rule, added as a rule, never certified by panel judgement.

**(d) Cert-unpause precondition, restated.** DEC-b5978c's interim ("new certifications pause until D2 lands") is restated and generalized: new certifications unpause when BOTH — (1) the deterministic gate for the machine-checkable classes is built and live (the 0036/PE-MC checks per the D5 order + `mcv_chain_status`), AND (2) the certification panel is declared FIT per DEC-b5978c D1 on its reduced residual corpus (the mechanical cases removed per D5) WITH D2's moderator-overrule rule enforced. A certification issued before both holds is not valid under this regime. ("D2 lands" is now a conjunct inside (2), not the whole precondition.)

**(e) Open empirical item (G2), accepted, not settled here.** Whether the panel CAN be declared fit on the reduced residual corpus is an open empirical question (G2) — DEC-b5978c D1 is explicit that "fit" carries no statistical false-verify bound, and the residual corpus's achievable fitness has not been demonstrated. This ADR pins the PREDICATE and the regime; it does not assert that the panel is already fit on the residual corpus. The operator co-signed the wording with this caveat explicit.

## DEC-b5978c relationship

Retained, not superseded. DEC-b5978c D1 (N=5 fitness), D2 (moderator overrule), D3 (structured attribution), D4 (transport-fault-is-not-a-verdict) and D6 (manifest record) continue to govern the panel's residual fitness; D5 (rules before judgement) is the migration this ADR declares complete-in-direction. This ADR adds the missing regime declaration and the predicate; it changes which gate is primary, not DEC-b5978c's panel mechanics.

## Foundation

Meaning is evaluated once (Invariant I): "certified" now has one pinned predicate, ending the drift. Evidence is emitted, not inferred (Invariant VI): both the deterministic-gate result and the panel residual verdict are recorded on the certification record, recomputable. No lower-layer compensation: machine-checkable truth lives in the deterministic rule at its source, not in a panel net (DEC-c48b0f §4). This is a design act (DEC-c48b0f) — a missing declaration (the regime) named and written, not a detector.
