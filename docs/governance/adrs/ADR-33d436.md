# Platform Readiness & Legibility — program mandate, platform/tenant readiness split, and SSOT consolidation

## Context

No rationale recorded.

## Decision

The Platform Readiness & Legibility program (anchor TSK-4b2404) is consolidated into a single SSOT at bc-docs/docs/implementation/platform-readiness-program.md (+ overview/platform-readiness.md), superseding the bc-core design docs platform-functional-refactor-{plan,package}.md (R4), which become pointers. The program's canonical model: (1) Readiness = streamlined·governed·documented·proven-once-E2E, split two-layered along Object Life States (DEC-c9e623): PLATFORM readiness = OLS 01-14 / lanes L1-L9 + runtime-engine conformance, provable on a fixture/sandbox tenant (no customer onboarding); TENANT readiness = OLS 15-25 / lane L10 + the runtime (the Kaveri pilot), a downstream milestone that depends on platform readiness AND the Platform DB Foundation program. This corrects the prior framing that treated the Kaveri tenant walk as the platform proof. (2) Three cuts: 4 tracks T(closed)/R(the gate)/L/S(deferred) as the work axis; 10 locked lanes L1-L10 (DEC-a67bae/D590) as the ownership/artifact-family axis (source-onboarding and tenant-onboarding are workflows over lanes, not lanes; L10 reclassified as the platform->tenant boundary lane at OLS-14->15); design-plane vs execution-plane (DEC-c48b0f). (3) The current gate is closing Track R (runtime Foundation conformance + governing the execution-plane couplings), fixture-provable and decoupled from DB Foundation. (4) Operator UI coverage per lane/workflow is a documented readiness criterion (no black boxes); mapped gaps (L8 directory, L9 chain-audit, L10 tenant stubs) are Track-L door-walk backlog.</decision_text>
<parameter name="rationale_text">The program's authority was two files in the wrong repo (bc-core) while the converging Platform DB Foundation program got a clean bc-docs SSOT; concepts (tracks, lanes, planes, readiness definition) were scattered and the platform-vs-tenant readiness distinction was conflated (Kaveri, a tenant-OLS walk, was used as the platform proof). A single SSOT + this mandate fixes both, operator-ratified 2026-09-19.
