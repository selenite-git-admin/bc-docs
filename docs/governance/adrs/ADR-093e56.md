# Governed primary within a pinned leg: one admission run per grain group, lowest admission_id, row-local inputs must agree (minimal DEC-a57eb8 amendment; latest-by and CO succession stay deferred)

## Context

The resolver's primary is "the first row the database returns" (ccv2-canonical-resolver groupByIdentity), which is order-dependent and ungoverned; W9 finding F3 and Codex gen-793604-02/03 R2 make a governed selector a prerequisite of implementation and 7d. The full latest-by + CO-succession design is not needed for 7d (one re-observation run under OC 1.3.0), so the minimal rule decides only what 7d exercises and refuses everything else (fail closed, never an arbitrary pick). Foundation: location B (declared selection semantics); Inv I (meaning evaluated once, from one observation), II (no CO from an out-of-leg or ambiguous row), III (no relabel), IV (explicit primary rule), V (deterministic, no replay dependence on row order).

## Decision

Amends DEC-a57eb8 (and the "which observation is primary follows the existing resolver rule" clause of DEC-7a8cbc Decision 4). Scope: canonical resolution of ONE pinned CC leg after leg scoping (TSK-2bc043; W9 successor 2 §2, Codex gen-793604-03 design B): only Source Object rows whose typed run context pins the leg's OC version are eligible.

1. Grain group. Eligible rows are grouped by the grain entity's declared identity (DEC-a57eb8 D1, DEC-7a8cbc carriers incl. connection + SC scope). Unchanged.

2. One run per group. Every row of a group must come from the SAME admission run. A group whose rows span two or more runs (a repeated observation of the same record) is REFUSED for this resolution: no CO is written for it, the refusal is counted (cosFailed) and recorded in the run result with reason repeated_observation_across_runs and the admission ids. The platform does not choose between observations in this ADR.

3. Primary. Within the one run, the primary is the row with the lowest admission_id. Deterministic and independent of database row order.

4. Row-local agreement (tie equivalence). Every column the resolver reads from the primary alone must be equal across the group's rows: identity carriers, value fields, row-local derivation inputs including unmapped raw signals (e.g. company_id), the posting date, the sign indicator, merged secondary columns and, for a binding-realized identity, the observed time the binding is as-of. Any difference refuses the group (reason conflicting_row_local_inputs, with the differing fields). Inputs of group-scoped derivations (D517 group_sum_where) are exempt: by declaration they aggregate over every row of the group, and because every row is from one run (point 2) a historical revision can never be counted as a distinct additive fact.

5. Deferred, explicitly (not decided here): a latest-by selector across runs (observation cutoff, latest observed_at), and CO succession (how a later observation of an already-resolved record becomes a new CO and how metric evaluation selects among them). Until a successor ADR decides them, point 2 refuses. Existing COs are never rewritten or relabelled (Invariant III).

Operational consequence: a leg is re-observed once per resolution window; a second re-observation under the same OC version makes its groups refuse until the latest-by ADR lands (7d re-observes exactly once).
