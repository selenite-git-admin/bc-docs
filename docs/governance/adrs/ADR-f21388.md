# Reduced-panel fitness is a single capped measurement — never an iterative tuning loop

## Context

Operator decision 2026-10-13. Touching the panel's scope/prompts/mechanics risks an open-ended calibration rabbit-hole (scope edit -> re-measure -> tune prompt -> re-measure ...), each turn calibration-locked and needing an operator sign-off — the exact iterative churn to avoid (ceremony scales to consequence; round-cap discipline). The deterministic gate already achieved the scope reduction with zero panel change, so no mechanics change is needed to realize the benefit; only a bounded confidence check remains. Capping it at one measurement with a stop-and-report on failure gives one honest data point without opening a program. If the single measurement fails, the regime is reconsidered deliberately with the operator + Architect, not patched by tuning.

## Decision

The residual certification-panel's fitness, now that the deterministic machine gate carries the mechanical classes, is established by ONE bounded fitness measurement — and that measurement IS the existing DEC-b5978c D1 run, unchanged: the predeclared N=5 calibration set over the reduced residual corpus, judged by D1's asymmetric FIT predicate on the completed-observation denominator. The "cap" forbids ITERATION ONLY: no change to the panel's scope, prompts, or mechanics, and no tune-and-re-measure loop. It does NOT reduce N and does NOT weaken or alter the D1 predicate; a one-ATTEMPT (N=1) FIT reading is explicitly NOT permitted. Concretely: (1) the deterministic checks (grain, misbound, calendar-context, plus the already-live closure-formula and kernel-coherence) sit in front of the panel and block their defect classes at the envelope door, so the panel's effective scope is reduced BY CONSTRUCTION with the panel unchanged. (2) Run the D1 N=5 fitness measurement once over the reduced residual corpus, judged by the unchanged D1 asymmetric FIT predicate, with the pass/fail bar fixed before the run. (3) A PASS proceeds to certification-unpause. (4) A weak or FAILING D1 result is STOP-AND-REPORT to the operator and Architect as a finding; it does NOT trigger a prompt cut, a scope edit, or any tuning / re-measurement loop. The previously-planned first-cert prompt-version cut is explicitly OUT. The per-metric residual FIT verdict required by DEC-92f709 is unchanged. This ADR PRESERVES DEC-b5978c D1 unchanged — it binds the capped measurement TO D1 — and governs only that the fitness exercise runs ONCE, without an iterative tuning loop.
