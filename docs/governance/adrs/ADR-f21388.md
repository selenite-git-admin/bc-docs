# Reduced-panel fitness is a single capped measurement — never an iterative tuning loop

## Context

Operator decision 2026-10-13. Touching the panel's scope/prompts/mechanics risks an open-ended calibration rabbit-hole (scope edit -> re-measure -> tune prompt -> re-measure ...), each turn calibration-locked and needing an operator sign-off — the exact iterative churn to avoid (ceremony scales to consequence; round-cap discipline). The deterministic gate already achieved the scope reduction with zero panel change, so no mechanics change is needed to realize the benefit; only a bounded confidence check remains. Capping it at one measurement with a stop-and-report on failure gives one honest data point without opening a program. If the single measurement fails, the regime is reconsidered deliberately with the operator + Architect, not patched by tuning.

## Decision

The residual certification-panel's fitness, now that the deterministic machine gate carries the mechanical classes, is established by exactly ONE capped measurement of the CURRENT panel on the reduced residual corpus — with NO change to the panel's scope, prompts, or mechanics, and NO iteration. Concretely: (1) The deterministic checks (grain, misbound, calendar-context, and the already-live closure-formula + kernel-coherence) sit in front of the panel and block their defect classes at the envelope door, so the panel's effective scope is reduced BY CONSTRUCTION, with the panel itself unchanged. (2) To gain confidence in the panel on what remains, run a SINGLE measurement of the current panel (unchanged prompt/version) over the reduced residual corpus, with a pass/fail bar fixed before the run. (3) A PASS proceeds to certification-unpause. (4) A weak/fail result is a STOP-AND-REPORT to the operator and Architect as a finding — it does NOT trigger a prompt cut, a scope edit, or any tuning/re-measurement loop. The previously-planned "first-cert prompt version cut" is explicitly OUT of the fitness path. The per-metric residual FIT verdict required by DEC-92f709 is unchanged — the panel is used as-is per metric; this ADR governs only the META fitness exercise, bounding it to one round.
