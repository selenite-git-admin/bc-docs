# ADR-ERR-005 — DEC-623f8f names an enforcer that does not exist and two automations that were never built

## Contradiction summary

DEC-623f8f (the ADR Hygiene Policy, `decided`, 2026-04-22) states in rule 1 that "`scripts/adr-audit.js` fails CI if any `target-not-flipped-to-superseded` issue is present in a PR diff", in rule 4 that "`scripts/adr-audit.js` runs monthly via CI/cron" with a trend record in `docs/governance/adr-audit-history.md`, in rule 2 that an ADR left `proposed` for more than 30 days "auto-spawns a DevHub task tagged `adr-stuck-proposed`", and in its Rollout that the script ships in a monthly cron and a post-merge hook flips status on `closes:` tokens.

Verified on 2026-09-30 at bc-docs main `aa5b743`: no file named `scripts/adr-audit.js` exists in bc-docs; the auditor is `scripts/docs-control/audit_adrs.py` (npm script `docs:audit:adrs`), and `.github/workflows/adr-hygiene.yml` runs it on every push to main and every pull request, failing on supersession issues. No `adr-stuck-proposed` task has ever been spawned in DevHub; no scheduled workflow exists; `docs/governance/adr-audit-history.md` does not exist; no post-merge `closes:` hook exists.

## Implementation behavior

Rule 1 is enforced, by a differently named tool and on every push rather than only on a pull-request diff. Rule 2 is checked by the same auditor on every run and reported as advisory text, never as a task. Rule 4 has no schedule and no history file. Rule 3's status flip on `closes:` is a manual act.

## Resolution state

**Adopted as a correction; DEC-623f8f is not rewritten.** The policy stands with its eight rules. Readers of DEC-623f8f substitute `scripts/docs-control/audit_adrs.py` for the named script, and read rules 2 and 4 as decided but unbuilt. Building them is a structural-integrity package (Codex-approved before code, each gate proven to go red once), tracked as the successor of TSK-914ab4. The ADR registry README, regenerated by `scripts/docs-control/generate_adr_registry.py`, no longer names the absent script.
